# Road Accidents Analysis and Prevention

Analysis of road accidents on India State Highways (2018-2021).

## Tools Used
Python, MySQL, Pandas, NumPy, Tableau

## Objective
Find accident patterns (time, location, cause) and suggest prevention measures.

## Key Findings
- highest risk state/highway
